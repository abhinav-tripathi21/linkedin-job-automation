# Automated Job Application System

## Description
This project automates job searching on LinkedIn and sends applications with resume attachment via email.

## Features
- LinkedIn job scraping using Playwright
- Email automation using SMTP
- Resume attachment system
- CSV job tracking

## Tech Stack
Python, Playwright, SMTP, Pandas

## How to Run
1. Install dependencies: pip install -r requirements.txt
2. Add .env file with credentials
3. Run: python main.py
